# Jimmy Paolini — Repository Agent Guide

## Repository Overview

This is Jimmy Paolini's GitHub profile repository. The `README.md` in the root is rendered as the GitHub profile page and contains technology icon badges organised into sections.

## Code Generator

The `README.md` is generated by `tools/code-generator` using **Mustache** templates. Do not edit `README.md` directly — edit the data or template and then regenerate.

### Structure

```
tools/code-generator/
├── package.json              # dependencies (mustache, tsx, typescript)
├── tsconfig.json
├── src/
│   ├── data.json             # all icon data (technologies, links, dimensions)
│   └── generate.ts           # renders template → README.md
└── templates/
    └── README.mustache       # Mustache template for README.md
```

### Running the generator

```bash
# From the repository root:
npm run generate

# Or from the tool directory:
cd tools/code-generator
npm run generate
```

### Adding a technology icon

1. Add the icon file to `assets/icons/`.
2. Add an entry to the appropriate section/subsection in `tools/code-generator/src/data.json`:

```json
{
  "alt": "my-tool",
  "src": "assets/icons/my-tool.png",
  "href": "https://my-tool.io",
  "width": 64,
  "height": 64
}
```

   - Omit `width` for height-only icons (e.g. `"height": 64`).
   - Omit `height` for width-only icons (e.g. `"width": 64`).
   - For URLs that contain parentheses (which would break Markdown link syntax), wrap the URL in angle brackets: `"href": "<https://example.com/path_(with_parens)>"`.

3. Run `npm run generate` from the repository root.
4. Commit both the updated `data.json` and the regenerated `README.md`.

### Modifying the template

Edit `tools/code-generator/templates/README.mustache`. The template uses [Mustache](https://mustache.github.io/) syntax:

- `{{value}}` — HTML-escaped output (safe for simple strings like `alt` text).
- `{{{value}}}` — unescaped output (used for `src`, `href`, `imgAttrs`, section titles, and trailing content that may contain `&`, `<`, `/`, etc.).
- `{{#section}}...{{/section}}` — renders the block for each item in an array, or once if the value is truthy.
